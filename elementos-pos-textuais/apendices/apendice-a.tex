
\chapter{Tabelas de Exportação}
\label{sec:anexo-tabela-exportacao}

Tabelas de exportação dos dados coletados, disponíveis no painel de registros do aplicativo. Estas tabelas são gerada em formato \textit{Excel} (.xlsx) e contém os registros de fauna marinha coletados, permitindo a análise e o compartilhamento dos dados de forma prática e eficiente. A primeira tabela é destinada aos pesquisadores, enquanto a segunda é voltada para os cidadãos. Ambas as tabelas são apresentadas em formato paisagem para melhor visualização dos dados.
